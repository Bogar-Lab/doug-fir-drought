# Doug Fir Drought

This project examines the differentially expressed genes of Pseudotsuga menziesii in response to drought under mycorrhizal and non-mycorrhizal conditions.

## Features

* **Feature 1:** Use the "use-these-scripts" to run the code.
* **Feature 2:** Use "working-scripts" as reference for a longer, streamline code that hasn't been cleaned up. 

## Installation

Clone the repository

\`\`\`bash
# Clone this repository
git clone https://github.com/bklong/doug-fir-drought.git

# Navigate into the directory
cd doug-fir-drought
